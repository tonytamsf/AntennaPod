How AntennaPod's Plugin System Works

AntennaPod can now be extended by plugins — small helper apps that add features like transcripts and chapter markers to your podcast episodes. Here's how it works, no engineering background required.

The big idea

When you download a podcast episode, AntennaPod can now hand the audio file to a plugin app you've installed on your phone. That plugin does something useful with it — like generating a text transcript or adding chapter markers — and sends the result back. AntennaPod then shows the result just like it would if the podcast creator had included it themselves.

The key part: each plugin is a completely separate app on your phone. It has its own icon-less install, its own updates, and it runs in its own little sandbox. AntennaPod never runs the plugin's code directly — the two apps talk to each other through Android's built-in messaging system.

Think of it like…

Imagine you run a small bookshop. Instead of hiring a full-time translator, bookbinder, and illustrator, you send individual books out to independent specialists nearby. You hand them the book through a secure mail slot, they do their work, and they slide the result back. They never come inside your shop, they never touch your cash register, and if one of them is on vacation, your shop still runs fine. That's how AntennaPod plugins work.

What can plugins do?

Right now, plugins can add three kinds of content to your episodes:

📝

Transcripts

A plugin can listen to the audio and generate a written transcript. Once it's added, you can read along while listening, search through episodes by text, or catch up on a podcast without headphones.

📑

Chapter markers

A plugin can analyze the audio and divide it into chapters — "Intro," "Interview," "Wrap-up" — so you can skip to the parts you care about, just like chapters in a book.

🗑

Episode cleanup

A plugin can help manage storage by deciding which old episodes to remove — for example, keeping only the newest five episodes from a daily news show so your phone doesn't fill up.

How it works, step by step

Here's what happens from the moment you install a plugin to the moment you see its results:

📦

You install a plugin app

You download a plugin from its own source (like GitHub) and install it on your phone. It has no launcher icon — it's a behind-the-scenes helper. AntennaPod automatically detects it.

🔋

You turn it on

Open AntennaPod → Settings → Plugins. You'll see the plugin listed there. Toggle it on. Plugins are off by default — nothing runs until you say so.

⬇️

You download an episode

Subscribe to a podcast and download an episode like you normally would. Nothing different here.

🤝

AntennaPod checks what's missing

After the download finishes, AntennaPod looks at the episode: does it already have a transcript? Chapter markers? If something is missing and a plugin can provide it, AntennaPod reaches out.

📨

The audio is passed securely

AntennaPod gives the plugin read-only access to just that one audio file — nothing else. The plugin can't see your podcast list, your settings, or any other data on your phone.

⚙️

The plugin does its work

The plugin processes the audio in its own separate space on your phone. If it crashes or takes too long, AntennaPod simply moves on — your podcast app stays working.

✅

Results appear in your episode

The plugin sends back a transcript or chapter markers. AntennaPod saves them and displays them exactly like content the podcast creator included — you'll see a Transcript tab or chapter list when you open the episode.

Is this safe?

The plugin system was designed with safety as the top priority. Here are the protections built in:

🛡️

Completely separate

Each plugin runs in its own isolated space on your phone. If a plugin has a problem, it can't affect AntennaPod or any of your other apps.

🔒

Minimal access

A plugin only receives the single audio file it needs to work on. It can't read your podcast list, settings, contacts, photos, or anything else.

✋

You're in control

Plugins are off by default. You choose which ones to enable, and you can turn them off at any time. Uninstalling the plugin app removes it completely.

📱

Everything stays on your phone

Plugins run locally on your device. Your audio files are never uploaded to the internet or sent to any third-party server.

Play Store compatible

Unlike some plugin systems in other apps, AntennaPod's approach doesn't load or run plugin code inside the main app. This means it fully complies with Google Play Store rules, which is important for the app's long-term availability.

Why was it built this way?

The team considered several approaches before landing on this design. Here's a simplified look at the options and why this one was chosen:

✔ Chosen

Separate helper apps

Each plugin is its own small app on your phone. They communicate through Android's secure messaging. Safe, private, and each plugin updates independently.

✘ Rejected

Loading plugin code directly

Would be faster, but violates Play Store rules and means a buggy plugin could crash AntennaPod. Too risky.

✘ Rejected

Cloud processing

Would send your audio files to a server on the internet. Violates AntennaPod's core commitment to privacy and doesn't work offline.

✘ Rejected

Built into the main app

Simplest option, but every new feature would require an AntennaPod update. No way for independent developers to contribute plugins.

Available plugins

Two working plugins are already available to try:

📝

Transcription plugin

Generates text transcripts for downloaded episodes. Supports both transcription and chapter generation.

📑

Chapter marker plugin

Adds chapter markers to episodes that don't have them, so you can skip between sections.

Both are open source and can be used as starting points for anyone who wants to build their own plugin.
